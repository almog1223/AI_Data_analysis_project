# פרויקט מסכם: האם קורס הכנה קשור לציונים גבוהים יותר?

פרויקט מסכם בקורס ניתוח נתונים בעזרת AI. המאגר שנבחר: **ציוני תלמידים** (`Student_tests_results.xlsx`).

> **שאלת המחקר:** האם השלמת קורס הכנה קשורה לציונים גבוהים יותר גם כשמתחשבים במלגה ובהשכלת ההורים, ובאיזה מקצוע (מתמטיקה, קריאה או כתיבה) הקשר הזה חזק יותר?
>
> **התשובה בקצרה:** כן. הממוצע של תלמידים שהשלימו קורס הכנה גבוה יותר בכל קבוצות המלגה ובכל רמות השכלת ההורים. הפער הגדול ביותר הוא בכתיבה (‎+9.9 נקודות), אחריה קריאה (‎+7.3) ומתמטיקה (‎+5.4). זה קשר, לא בהכרח סיבה ותוצאה.

## התוצרים העיקריים

כל התוצרים נמצאים בתיקייה [`outputs/`](outputs/). כולם קבצים עצמאיים: אין צורך להתקין דבר או להריץ קוד כדי לפתוח אותם.

### 1. המצגת
**קובץ:** [`outputs/קורס הכנה וציוני תלמידים.pptx`](outputs/)

13 שקפים בעברית, לפי מבנה הסיפור שנלמד בשיעור "Delivering Insights": בעיה ← תהליך ← תובנות ← המלצה.

| שקפים | תוכן |
|---|---|
| 1–3 | פתיחה, הנתונים והמטרה, התהליך בשישה שלבים |
| 4–5 | ניקוי הנתונים ושתי מסקנות מהחקר |
| 6 | שאלת המחקר, ולמה נבחר דווקא קורס ההכנה |
| 7–9 | גרף עמודות, מפת חום והמספרים העיקריים |
| 10–11 | התשובה, המגבלות, הרפלקציה וההמלצה |
| 12 | לקחים מהעבודה עם AI: טעויות שנתפסו ותוקנו |
| 13 | סיום ושאלות |

**איך לפתוח:** ב־PowerPoint, ב־Keynote או ב־Google Slides.

### 2. הדשבורד
**קובץ:** [`outputs/dashboard.html`](outputs/dashboard.html)

דף אחד שעונה על שאלת המחקר. מלמעלה למטה:
1. **השאלה ומשפט התשובה.**
2. **גרף עמודות:** ממוצע הציון לפי השלמת קורס ומלגה, בכל אחד משלושת המקצועות.
3. **מפת חום:** הפער בנקודות בין מי שהשלים קורס למי שלא, לפי השכלת ההורים ומקצוע. בכל תא מופיע גם מספר התלמידים בכל קבוצה.
4. **שלושה מספרים עיקריים:** הפער הכללי בכל מקצוע.
5. **מסקנות ומגבלות.**

**איך לפתוח:** הורדה ופתיחה בדפדפן (לחיצה כפולה). הגרפים מוטמעים בקובץ, ולכן הוא עובד גם בלי אינטרנט. הדף מתאים גם למסך של טלפון.

### 3. מסמך הסיכום
**קבצים:** [`outputs/summary.pdf`](outputs/summary.pdf) (להדפסה ולקריאה) ו־[`outputs/summary.html`](outputs/summary.html) (לפתיחה בדפדפן). שני הקבצים מכילים את אותו תוכן.

מסמך שמתעד את הניתוח כולו, לפי המבנה שנלמד בשיעור:

| פרק | תוכן |
|---|---|
| 1 | מבוא ומטרה |
| 2 | שיטה וכלים (כולל שני סוכני ה־AI) |
| 3 | ניקוי הנתונים: מה נמצא ומה הוחלט |
| 4 | חקר הנתונים ושתי מסקנות |
| 5 | שאלת המחקר |
| 6 | ממצאים: מספרים, גרף וטבלת פערים |
| 7 | תשובה, מסקנות ומגבלות |
| 8 | רפלקציה והמלצה לבית הספר |
| 9 | לקחים מהעבודה עם AI |
| 10 | רשימת קבצים |

## איך התוצרים מתחברים לשלבי המשימה

| שלב במשימה | איפה למצוא |
|---|---|
| בחירת מאגר והבנת הנתונים | `students_tests_results_info.docx`, ופרק 1 במסמך הסיכום |
| ניקוי | `outputs/Student_tests_results_clean.csv`, `scripts/clean_students.py` |
| חקר ולפחות 2 מסקנות | `docs/02_exploration_report.md`, וגרפים 01–03 ב־`outputs/figures/` |
| שאלת מחקר | `docs/process_log.md` (שלב 3) |
| לפחות 2 גרפים ומבחן סטטיסטי | גרפים 04–05 ב־`outputs/figures/`, `scripts/analysis_graphs.py` |
| דשבורד | `outputs/dashboard.html` |
| תשובה ורפלקציה | `docs/03_answer_and_reflection.md` |
| הצגה | המצגת ומסמך הסיכום |
| תיעוד כל שלב | `docs/process_log.md` |

**לגבי הסטטיסטיקה:** השתמשתי בכלים שנלמדו בקורס: ממוצע, חציון ו־IQR. לא נעשה מבחן מובהקות, וזה מצוין כמגבלה בכל התוצרים.

## תיעוד התהליך

[`docs/process_log.md`](docs/process_log.md) הוא יומן מלא של העבודה, שלב אחרי שלב. בכל שלב מופיעים:
- מה המשימה דרשה, ומה נלמד במצגת הרלוונטית
- כל טיוטה של הפרומפט, המשוב שקיבלתי עליה, והגרסה הסופית שהורצה
- התוצאות
- טעויות שנתפסו בדרך ואיך תוקנו
- הלקח מכל שלב

### סוכני ה־AI
העבודה נעשתה בעזרת שני סוכנים עם תפקיד מוגדר, שההנחיות שלהם נמצאות בתיקייה [`Cleaning_agent/`](Cleaning_agent/):
- **נועה**, סוכנת ניקוי הנתונים: `1_data cleaning_agent.md`
- **יואב**, סוכן חקר הנתונים: `2_data exploration_agent.md`

### הרצת הקוד מחדש (לא חובה)
הקוד כתוב ב־Python 3 ודורש `pandas`, `openpyxl` ו־`matplotlib`. מתיקיית הפרויקט:

```bash
python scripts/clean_students.py      # ניקוי
python scripts/explore_students.py    # חקר וגרפים 01–03
python scripts/analysis_graphs.py     # גרפים 04–05
python scripts/build_dashboard.py     # בניית הדשבורד
```
